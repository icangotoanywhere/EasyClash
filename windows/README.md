# EasyClash Windows 版

> **声明：本应用仅支持科研用途，任何人不得借助本应用提供的便利浏览非法内容、发表非法言论，否则后果自负！**

安卓版 EasyClash 的 Windows 复刻：同样的五个页面、同样的说明文字和功能，**单个 exe，双击即用，不用安装**。

## 和安卓版一样的地方

- 首页：一键连接/断开；规则 / 全局 / 直连；按国家锁定出口（自动用该国最快节点）；单地区或全部地区测速；实时速度
- 订阅：添加链接（支持 `clash://` 一键导入）、从剪贴板、导入 .yaml；更新、重命名、删除；流量与到期
- 节点：树状显示策略组，测速、手动切换
- 高级：分流规则与地理数据库状态、拦截 QUIC、IPv6、DNS、本机代理端口、必应国内版、附加规则、YAML 覆写、日志与连接
- 规则集固定经代理下载、订阅没带规则时自动补基础分流、地理数据库每 7 天自动更新、港澳台显示为中国香港/中国澳门/中国台湾

## Windows 专有

| 安卓版 | Windows 版 |
|---|---|
| VPN（系统接管全部流量） | **系统代理**（默认，不需要管理员；断开/退出时自动恢复原设置）或 **TUN 虚拟网卡**（接管所有程序，需要管理员，界面里一键「以管理员身份重新启动」） |
| 分应用代理 | **分程序代理**：按程序名（如 chrome.exe）排除或只让选中的程序走代理，改动立即生效 |
| 下拉菜单磁贴、桌面长按快捷方式 | **托盘图标**：单击打开窗口，右键连接 / 断开 / 切换模式 / 退出；连接时图标变蓝 |
| — | 开机自动启动、启动后自动连接 |
| — | 连接期间系统代理被其他软件改掉时首页会提醒，并可一键改回 |
| — | 上次异常退出（崩溃、强制结束）后再次打开，会先把系统代理恢复原样 |
| — | 下载订阅时，没连接也会先借用系统里已开着的代理（比如另一个代理软件），连不上再直连，并自动重试 |
| — | 连接后自动测一下实际在用的节点，全部连不上时首页红字提醒（可「重新检测」、去换订阅或断开） |

关闭窗口不会退出，软件在右下角托盘继续运行（第一次关窗口时会提示一次）。设置和订阅保存在 `%APPDATA%\EasyClash`，日志保存在其中的 `logs\easyclash.log`（重启后也能查，超过 4 MB 自动换新文件）。

## 技术说明

- Go 单文件程序：mihomo 内核以库的形式在进程内运行（和安卓版的 `core/core.go` 同一思路），界面是内嵌的网页，用系统自带的 WebView2 显示（Windows 10/11 都已预装）。
- 内核版本固定为 v1.19.33（`core.go` 用到了它的地理数据库更新接口）。TUN 需要的 wintun 驱动已内嵌在内核里，不用另带 dll。
- 地理数据库（GeoIP / GeoSite / ASN）压缩后打包进 exe，首次连接时释放。
- Windows 自带字体没有国旗 emoji，界面内嵌了 [Twemoji Country Flags](https://github.com/talkjs/country-flag-emoji-polyfill) 字体（字形来自 Twemoji，CC-BY 4.0）。
- 界面服务只监听 127.0.0.1，并要求启动时随机生成的令牌，本机其他程序无法调用。

## 编译

右键 `build-windows.ps1` → 使用 PowerShell 运行，产物为本目录的 `EasyClash.exe`。需要 Go 1.26 以上（运行过上一级目录的 `setup-windows.ps1` 的电脑上已经有，会自动使用）。

```powershell
.\build-windows.ps1 -Version 1.0.0
```

测试用参数：`--headless`（不开窗口和托盘）、`--no-sysproxy`（不改系统代理）、`--data <目录>`（换数据目录）、`--ui-port <端口>`、`--check-config`（按当前设置生成配置并让内核检查，结果写到数据目录的 check-config.txt）。

## 卸载

先在「高级 → 启动与托盘」里关掉开机自动启动，从托盘退出，再删除 exe 和 `%APPDATA%\EasyClash` 文件夹即可。
