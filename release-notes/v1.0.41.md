## 改进（安卓）：Claude 从多任务切回来时也能弹出检查卡片

v1.0.40 的「Claude 联网前先确认」里，从多任务（后台）切回 Claude、或者直接点原版 Claude 图标时，不会弹窗——安卓不允许后台的 VPN 服务直接弹出界面。

现在「高级 → Claude 专用」里新增可选项「Claude 切到前台时自动弹出检查」（要在系统「无障碍」里手动打开，页面上有按钮直达和详细步骤）：

- Claude 被挡住时，不管从原版图标、多任务还是通知进入 Claude，都立刻弹出检查卡片盖在 Claude 上面；
- 点「打开」= 放行并露出 Claude（它会自己重新连上），点「取消」或返回键 = 回到桌面、继续挡住；
- 已经放行时不打扰；没开「Claude 联网前先确认」时也不打扰；
- 只接收「哪个 App 来到了前台」的通知，不读取屏幕内容，不收集、不上传任何信息。

同时去掉了 v1.0.40 的「Claude 想联网，已被挡住」通知提醒，统一用上面这个弹窗。没开无障碍服务时，从桌面的「打开 Claude」图标进去放行。

Windows 版和 macOS 版没有变化。v1.0.31 及以后的版本可以在「高级」→「版本与更新」里一键升级（需要能连上 GitHub，建议先连接 EasyClash）。
