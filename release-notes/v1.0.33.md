## 修复：Windows 版开着悬浮球时偶尔崩溃

- v1.0.32 打开「网络状态悬浮球」后，软件运行一段时间可能突然退出（「高级」页出现「上次异常退出记录」，里面有 `invalid pointer found on stack` / `adjustpointers`）。原因是悬浮球调用 Windows 接口时的一处内存问题，已修复。**用 v1.0.32 并打开了悬浮球的，请尽快升级。**

## 改进：悬浮球的线路显示

- 展开后的「线路」一行太长、显示不全：现在拆成两行——「线路」显示 EasyClash 和锁定的地区，「节点」单独一行显示节点名和延迟。
- 没走 EasyClash 时同样分两行：「线路 未使用代理 / 其他代理软件」，下一行说明原因（例如系统代理指向的地址）。

安卓版和 macOS 版没有变化。v1.0.31 及以后的版本可以在「高级」→「版本与更新」里一键升级（需要能连上 GitHub，建议先连接 EasyClash）。
