## 新功能：安卓状态栏图标轮换显示出口国家和延迟

- 连接后，状态栏上 EasyClash 的小图标会轮流显示：**EasyClash 图标 → 出口国家（如 JP）→ 延迟数字**。
- 延迟好坏一眼可见：200 毫秒以内只显示数字，200～500 加一个方框，更慢或超时变成实心方块（超时显示 `--`）。
- 下拉通知栏后，通知卡片整张按延迟变色：**绿色**（200 毫秒以内）、**黄色**（200～500）、**红色**（更慢或超时）。
- 「高级」→「通知与快捷开关」里可以关掉，或选择每 1 / 2 / 3 秒切换一次（默认 2 秒）。
- 息屏时不刷新，不额外耗电。

说明：钥匙形状的 VPN 图标是安卓系统画的，任何 App 都改不了。部分手机系统在状态栏显示的是 App 原本的彩色图标，或者不显示通知图标，那样就看不到轮换。

Windows 版和 macOS 版没有变化。v1.0.31 及以后的版本可以在「高级」→「版本与更新」里一键升级（需要能连上 GitHub，建议先连接 EasyClash）。
