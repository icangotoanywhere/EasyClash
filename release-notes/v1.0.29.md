## 改动

- **分应用设置退回 1.0.27 的方式**：「全部应用 / 仅选中的应用 / 排除选中的应用」。1.0.28 的「每个 App 三选一」会让手机上网略有卡顿，所以撤回。
  - 1.0.28 里设为「仅直连」的 App / 程序，会自动换成「排除选中的应用」名单，不用重新勾选；设为「仅代理」的没有对应项，恢复为正常按规则。
- **新增「国际 AI 服务强制走代理」**（高级页，默认开，安卓 / Windows / macOS 都有）：ChatGPT、Claude、Gemini、Perplexity、Grok 等网站一律走代理（首页选的出口地区），绝不直连。万一按规则要直连会自动改走代理，代理不可用就打不开，不会暴露真实 IP。App 和浏览器里用都受保护；只按域名判断，不拖慢网速。

安卓从 v1.0.25 及以后的版本升级可直接覆盖安装。
