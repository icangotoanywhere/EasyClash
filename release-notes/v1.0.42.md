## 改进（安卓）：通知里的延迟一眼可见，并去掉国旗

通知栏的常驻通知有两处变化：

- **按延迟变色的圆形图标**：圆里写着当前延迟的毫秒数，绿色 = 150 ms 以内，黄色 = 150～300 ms，红色 = 更慢或超时，灰色 = 还没测过。直连 / 拒绝时不显示。
- **延迟前的彩色圆点**：「延迟 90 ms」前面加 🟢 / 🟡 / 🔴（未测为 ⚪），分档和图标一致；即使系统不显示图标，也能看出好坏。
- **去掉国旗**：标题里只保留国家（地区）名称和节点名，不再显示 🇯🇵 这类旗帜；节点名里订阅自带的旗帜也会去掉。

说明：整张通知卡片的背景色是系统画的，荣耀等系统不允许应用修改，所以改用图标来表示延迟好坏。

Windows 版和 macOS 版没有变化。v1.0.31 及以后的版本可以在「高级」→「版本与更新」里一键升级（需要能连上 GitHub，建议先连接 EasyClash）。
