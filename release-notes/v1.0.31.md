## 新功能：App 内检查更新、一键原地升级（安卓 / Windows / macOS）

- **「高级」页新增「版本与更新」**：显示当前版本和最新版本，列出最近 3 个版本的更新内容；点「升级到 vX」即可原地升级。
  - 安卓：下载新安装包，交给系统安装器覆盖安装。第一次会要求允许 EasyClash「安装未知应用」，允许一次即可。安装时 VPN 会断开，装好后重新打开连接。
  - Windows：下载后原地替换 EasyClash.exe，自动重新启动。程序位置不变，开机自启照常有效。
  - macOS：下载后原地替换 EasyClash.app，自动重新启动。
  - **订阅和设置都会保留。**
- **自动提醒**：打开软件后会自动检查一次（电脑版之后每 12 小时一次），有新版本时首页会提示。
- ⚠️ **升级从 GitHub 下载**，请保持能连上 GitHub。建议先连接 EasyClash：连接后会自动走代理下载。

从这一版开始可以在 App 里升级；**v1.0.30 及更早的版本需要手动下载安装这一版一次。**

安卓从 v1.0.25 及以后的版本升级可直接覆盖安装。
