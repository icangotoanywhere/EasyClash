## 新功能（安卓）：Claude 联网前先确认

「高级」页新增「Claude 专用」卡片，「在桌面创建「打开 Claude」图标」也挪到了这里。新开关「Claude 联网前先确认」（默认关）：

- **前提**：桌面上要有「打开 Claude」图标，它是放行的入口。没有这个图标时，开关开着也不起作用，EasyClash 不看管 Claude；图标被删掉后会自动停止看管。
- **开启后**，平时挡住 Claude 的网络连接（claude.ai、claude.com、anthropic.com、claudeusercontent.com），Claude App 会显示网络错误。
- 从桌面的「打开 Claude」图标进去，看过网络卡片、点「打开」，才放行。卡片上会显示「Claude 联网：已挡住 / 已放行」。
- **放行多久**可选：直到锁屏（默认）、30 分钟、2 小时。到时间后重新挡住，并断开已有的 Claude 连接。
- 直接点了原版 Claude 图标也没关系：Claude 一联网被挡住，通知栏会弹「Claude 想联网，已被挡住」，点它就能打开检查卡片放行。
- 按网站挡、不分 App（手机浏览器里的 claude.ai 也一样），只在规则模式下起作用。

## 改进（安卓）：「打开 Claude」图标跟着 Claude 换图标

以前要打开一次 EasyClash 才会刷新；现在 EasyClash 连着时，Claude 一升级，桌面上的「打开 Claude」图标就自动跟着换。

Windows 版和 macOS 版没有变化。v1.0.31 及以后的版本可以在「高级」→「版本与更新」里一键升级（需要能连上 GitHub，建议先连接 EasyClash）。
