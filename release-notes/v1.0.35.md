## 修复：Windows 版「清除」异常退出记录的按钮没反应

- 「高级」→「诊断」里「上次异常退出记录」下面的「清除」按钮，在 Windows 上点了没反应（记录文件被程序占用，删不掉）。现在改成清空记录，可以正常清除了。
- 清除前会先弹出确认，免得误点；还没把记录发出去排查的，建议先点「复制崩溃记录」。

## 撤回：安卓状态栏图标轮换和通知卡片变色

v1.0.34 加的「状态栏图标轮换显示出口国家和延迟」「通知卡片按延迟变色」，在荣耀、华为等手机上系统都不显示，已整个去掉，通知恢复成 v1.0.33 的样子（节点、延迟、速度和「测速」按钮照旧）。

macOS 版没有变化。v1.0.31 及以后的版本可以在「高级」→「版本与更新」里一键升级（需要能连上 GitHub，建议先连接 EasyClash）。
