## 新功能：Windows 版网络状态悬浮球

- **「高级」页 →「启动与托盘」新增开关「显示网络状态悬浮球」**（默认关）。打开后桌面上出现一个小球，显示出口 IP 所在地和实时网速。
- **双击展开**看详细信息：出口 IP、所在地、运营商，以及 **EasyClash 当前的节点线路**（含延迟、锁定的地区）。
  - 没有走 EasyClash 时，线路一行会显示「未使用代理」，或者「其他代理软件」（系统代理指向了别的软件）。
- 右键菜单可以刷新、复制信息、隐藏悬浮球（隐藏后可以在「高级」页重新打开）。
- 已经在用单独的 NetGateShow 小工具的，可以关掉它，改用这个。

macOS 版和安卓版没有变化。v1.0.31 及以后的版本可以在「高级」→「版本与更新」里一键升级（需要能连上 GitHub，建议先连接 EasyClash）。
