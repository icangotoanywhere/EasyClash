## 新功能：安卓桌面「打开 Claude」图标

- 「高级」→「通知与快捷开关」里新增按钮「在桌面创建「打开 Claude」图标」。桌面上会多一个 Claude 图标（右下角带 EasyClash 小标，和原来的 Claude 图标区分开）。
- 点这个图标，先弹出当前网络情况：
  - EasyClash 有没有连接；
  - Claude 会走哪个节点（含锁定的地区和延迟）；
  - 出口 IP、所在地、运营商（和电脑上的 NetGateShow 显示的差不多）。
- 发现问题会直接提醒：EasyClash 没连接、Claude 不会经过代理、Claude 被「应用」页排除在外、出口在 Claude 不提供服务的地区（中国大陆、香港、澳门、俄罗斯等）。
- 下方两个按钮：左边「取消」，右边「打开」拉起手机上的 Claude App（没装的话跳到应用商店）。没连接时左下角可以直接「连接 EasyClash」。
- 如果点了按钮桌面上没出现图标，请在系统设置 → 应用 → EasyClash → 权限里，允许「创建桌面快捷方式」。

Windows 版和 macOS 版没有变化。v1.0.31 及以后的版本可以在「高级」→「版本与更新」里一键升级（需要能连上 GitHub，建议先连接 EasyClash）。
