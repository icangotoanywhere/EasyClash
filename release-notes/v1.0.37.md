## 改进：安卓桌面「打开 Claude」图标去掉多余的小标

- v1.0.36 创建的 Claude 图标自带一个 EasyClash 小标，而手机桌面本身也会给快捷方式加一个，结果出现两个错开的小标，看起来像出了问题。现在图标就是 Claude 原本的样子，只保留系统加的那个小标。
- 已经放在桌面上的图标，升级后打开一次 EasyClash 就会自动换成新样子，不用删掉重建（如果没变，再到「高级」页点一次「在桌面创建「打开 Claude」图标」）。

Windows 版和 macOS 版没有变化。v1.0.31 及以后的版本可以在「高级」→「版本与更新」里一键升级（需要能连上 GitHub，建议先连接 EasyClash）。
