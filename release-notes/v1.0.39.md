## 撤回「锁定地区时核实节点出口」，改用更准的 IP 查询服务

v1.0.38 加的「切换节点前先查实际出口 IP」撤回了。原因是查询服务给的地区本身就可能不对：

- 一个标「日本」的节点，ip-api.com 查出来是香港；
- 但经这个节点实测，到东京机房的延迟比到香港低约 60 毫秒，到新加坡更慢，说明它实际就在日本；
- 几家查询服务的说法也不一致：ip-api.com、ipapi.co、IP2Location 说香港（这个 IP 是登记在香港的公司名下），ipwho.is、ip.sb 说日本。

所以按查询结果自动换节点，反而可能把好好的节点换掉。现在：

- 锁定地区后照旧自动用该地区最快的节点，不再核实出口；v1.0.38 钉住的节点会在连接时自动取消钉住；
- 查出口 IP 的地方（安卓「打开 Claude」前的网络卡片、Windows 悬浮球）改为优先用 ipwho.is，查不到再用 ip-api.com。

v1.0.31 及以后的版本可以在「高级」→「版本与更新」里一键升级（需要能连上 GitHub，建议先连接 EasyClash）。
